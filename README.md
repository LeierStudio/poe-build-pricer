# PoE 裝備查價

貼上 Build 網址（例如 pobb.in），自動到 Path of Exile 國際服市集，查出這套 Build 每件裝備目前賣多少錢。

---

## 一般玩家：下載這裡

### 👉 [按這裡下載最新版](https://github.com/LeierStudio/poe-build-pricer/releases/latest)

在下載頁面的 **Assets** 裡，點最上面的 **.zip 檔**（例如 `PoE.zip`）下載。

> ⚠ 不要點「Source code」，也不要按綠色的「Code → Download ZIP」，那些是程式原始碼，不能直接用。

### 怎麼用

1. 把下載的 zip **解壓縮**（右鍵 →「解壓縮全部」）
2. 雙擊 **「PoE裝備查價.exe」**，瀏覽器會自動打開查價網頁
3. 貼上 Build 網址，按 **「查詢價格」**，等它查完

第一次開啟如果出現「Windows 已保護您的電腦」，請按 **「其他資訊」→「仍要執行」**。

詳細說明請看 zip 裡的「使用說明.txt」。

## 開發者

以下給要修改程式的人看，一般玩家不用理會。

### 執行原始碼

需要 Node.js 22 以上（不用安裝其他套件）：

```
start.bat        或   node server.js
```

瀏覽器開啟 <http://localhost:5577/>。

### 打包成 exe

```
node build.js
```

產生 `dist/PoE裝備查價/`（exe + 使用說明）與 `dist/PoE裝備查價.zip`，把 zip 上傳到 GitHub Releases。
使用者看的說明在 `release/使用說明.txt`，改內容後重新打包即可。

### 查價方式

| 物品 | 查詢條件 |
| --- | --- |
| 傳奇 | 名稱、汙染狀態、5 連以上連線數、固有／汙染詞綴、隨機詞綴數值（≥85%） |
| 傳奇珠寶 | 加上詞綴種類（Watcher's Eye 等）、永恆珠寶種子 |
| 稀有 | 詞綴對應官方 stat，抗性與生命合併成 pseudo 總和 |
| 星團珠寶 | 天賦數、小天賦類型相同，再比對大天賦 |
| 魔法藥劑 | 從名稱拆出基底，比對前後綴數值 |

找不到時逐步放寬條件，放寬後的結果標示「僅供參考」。

### 官方限流

- 搜尋：10 秒 5 次、60 秒 15 次、300 秒 30 次（同一 IP 共用），超過會被暫停 1～30 分鐘
- 每條規則各自計數，並依回應標頭與伺服器狀態同步；搜尋間隔預設 2 秒，網頁可調（最短 2 秒）
- 相同查詢 15 分鐘內使用快取

### 繁體中文

- 物品名稱／基底：台服官方 trade 資料（與國際服清單序列對齊），對不上的用 Awakened PoE Trade 繁中資料
- 詞綴：比對到官方 stat id 後套用台服中文模板

### 檔案

| 路徑 | 說明 |
| --- | --- |
| `server.js` | 本機伺服器（查價以背景工作 + 網頁輪詢進度） |
| `lib/pob.js` | 解析 PoB 匯出碼與裝備 |
| `lib/trade.js` | 限流、詞綴對應、查價、繁中翻譯 |
| `public/index.html` | 操作介面 |
| `build.js` | 打包 exe |
| `release/使用說明.txt` | 打包進 zip 給玩家看的說明 |
