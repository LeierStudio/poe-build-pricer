# PoE Build 裝備查價工具（國際服）

貼上 pobb.in 網址，自動到 Path of Exile 國際服當季交易市集查詢每件裝備的價格。

## 使用方式

1. 雙擊 `start.bat`（需要 Node.js 18 以上，不用安裝其他套件）
2. 瀏覽器會自動開啟 <http://localhost:5577/>
3. 貼上 `https://pobb.in/xxxx`（也支援 pastebin、poe.ninja/pob 連結或直接貼 PoB 匯出碼）→「讀取 Build」
4. 讀取後會自動查價；價格顯示在「最低」「中位數」欄（可取消勾選後按「開始查價」重查）

## 查價方式

| 物品 | 查詢條件 |
| --- | --- |
| 傳奇 | 名稱 + 基底；未汙染時排除汙染品 |
| 傳奇珠寶（Watcher's Eye、Impossible Escape、永恆珠寶…） | 名稱 + 詞綴（永恆珠寶含種子），查無則逐步放寬 |
| 稀有 | 詞綴對應到官方 stat，數值下限預設 85%；抗性、生命合併成 pseudo 總和；查無則放寬為 n-1、n-2 條 |
| 星團珠寶 | 天賦數、小天賦類型必須相同，再比對大天賦 |
| 普通 / 魔法 | 不估價 |

- 價格顯示「在架最低」與「前 10 筆中位數」，合計使用中位數
- Divine 匯率取自官方通貨交易所；其他通貨（mirror 等）也會自動換算
- 查詢方式欄出現紅色 ⚠ 表示條件已放寬，價格僅供參考；點「開啟」可在官方市集（繁中介面）調整條件

## 注意

- 官方 API 有限流（搜尋約 5 次/10 秒、30 次/5 分鐘），工具會自動等待，整套 build 約需 5～10 分鐘
- 相同查詢 15 分鐘內會使用快取
- 詞綴對照資料快取在 `data/stats.json`，每 24 小時自動更新；新賽季若對應異常可刪除此檔
- 環境變數 `PORT` 可改埠號（預設 5577）

## 檔案

- `server.js`：本機伺服器
- `lib/pob.js`：解析 PoB 匯出碼與裝備
- `lib/trade.js`：Trade API 限流、詞綴對應、查價
- `public/index.html`：操作介面

## 繁體中文

- 物品名稱 / 基底：以台服官方 trade 資料為準（與國際服清單序列對齊），對不上的用 Awakened PoE Trade 繁中資料
- 詞綴：比對到官方 stat id 後套用台服中文模板；滑鼠移到詞綴上可看英文原文
- 稀有物品的名稱是隨機英文組合字，沒有官方對照，改以中文基底顯示
- 翻譯資料快取在 `data/zh_*.json`，每 72 小時更新

## 給別人用（不需安裝任何東西）

1. 執行 `node build.js`
2. 把 `dist/PoE裝備查價.zip` 傳給對方（內含 `PoE裝備查價.exe` 與 `使用說明.txt`）
3. 對方解壓後雙擊 exe 即可；第一次若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」

- 使用者看的說明寫在 `使用說明.txt`，改內容後重新 build 即可
- 重複開啟時，新視窗會自動關閉舊的查價視窗，不會出現埠號衝突
